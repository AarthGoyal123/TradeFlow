# Roadmap

## Phase 1 - Foundation

- Initialize repository structure.
- Create documentation and knowledge base.
- Define architectural boundaries.
- Establish processing foundation contracts.

## Phase 2 - Backend API

- Implement FastAPI service shell.
- Expose template and job endpoints.

## Phase 3 - Processing Engine

- Implement configurable Excel processing pipeline.
- Preserve plugin-based stage registration and `ProcessingContext`.
- Generate clean, removed, review, and report outputs.

## Phase 4 - Rule Engine

- Add keyword, regex, fuzzy matching, and confidence scoring.

## Phase 5 - Frontend

- Build upload, template selection, processing status, and download workflow.

## Phase 6 - Testing

- Add unit, integration, and fixture-based regression tests.

## Phase 7 - Polish

- Improve UX, reporting, validation diagnostics, and deployment readiness.
