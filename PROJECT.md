# Project

## Name

TradeFlow

## Goal

Build a production-grade, configurable Excel processing platform that automates trade data cleaning and importer identification.

## MVP Outcome

The first client should be able to upload an Excel workbook, choose a processing template, and receive cleaned output files in under 30 seconds for the target workflow.

## Current Phase

Phase 1: project initialization, documentation, repository structure, and knowledge base.

Initial backend and frontend shells have been created.
The backend now has architecture boundaries, typed template validation, structured errors/logging, and a plugin-based processing foundation.
The next product milestone is exposing template loading through the API before implementing workbook processing.

## Working Agreement

- Keep documentation updated during every coding session.
- Review `knowledge/` before feature implementation.
- Update knowledge files before code when new requirements change implementation.
- Ask the project owner before changing documented architecture when requirements conflict.
