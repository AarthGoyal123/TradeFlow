# TradeFlow Documentation

Welcome to the TradeFlow documentation index. TradeFlow is being developed over multiple phases into a production-grade SaaS platform for intelligent template-driven Excel processing.

## Documentation Map

*   **[Architecture](architecture/)**: System diagrams, phase plans, and high-level boundaries.
*   **[Architecture Decisions (ADR)](decisions/)**: Immutable records of important architectural choices.
*   **[API Reference](api/)**: Endpoints, request/response schemas, and error codes.
*   **[Processing Engine](processing/)**: How the intelligence engine detects, normalizes, routes, and outputs data.
*   **[Templates](templates/)**: How to configure and maintain data cleaning templates (e.g., Indian Rice Exports).
*   **[Security](security/)**: Threat model, file handling safety, and future tenant isolation.
*   **[Testing](testing/)**: QA boundaries, the golden regression test, and CI pipelines.
*   **[Deployment & Operations](deployment/)**: Roadmaps for infrastructure, containerization, and production.
*   **[Operations (Local)](operations/)**: Developer guide for local running, troubleshooting, and logs.

For a concise summary of the codebase intended for AI coding agents and new developers, see [`AI_CONTEXT.md`](../AI_CONTEXT.md).
